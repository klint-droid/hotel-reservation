# Staycation Reservation & Endorsement System

A Google Workspace-based reservation management and endorsement workflow built with Google Forms, Google Sheets, Google Apps Script, Google Docs, Google Drive, and Gmail.

## Overview
- Collects staycation booking requests via Google Forms.
- Supports manual administrator review and approval in Google Sheets.
- Generates personalized PDF reservation endorsement certificates and delivers them via email upon administrator approval.

## Tech Stack
- Google Forms
- Google Sheets
- Google Apps Script (V8)
- Google Docs & Google Drive
- Gmail

## Setup
Configure the project in Google Apps Script using your own Google Workspace resources and administrator settings before deployment.
